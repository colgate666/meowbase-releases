Meowbase

A fast, minimal database viewer

For SQLite, PostgreSQL and MySQL. Built for the Mac, drawn on the GPU, and happy with a million rows.

Download for macOS
Apple Silicon · macOS 11 or later

What it does

  • Browse any tablePages are fetched as you scroll, so a table of millions of rows opens at once. Sort and filter on the whole table.
  • Query editorSQL highlighting, run a statement, a selection or everything, stop it any time, and a history per connection.
  • Files of any sizeRun a multi-gigabyte .sql dump from disk, including pg_dump's COPY format, without loading it into memory.
  • Import and exportCSV, TSV and SQL for tables and for query results. Import a CSV into a table, or create a new table from it.
  • Edit in placeChange cells, add and delete rows, review the SQL, and commit it all in one transaction.
  • Your passwords stay yoursSaved in the macOS Keychain, never in a file. Mark a connection read-only when you only want to look.

Install

  1. Download the disk image above and open it.
  2. Drag Meowbase onto the Applications shortcut, and open it from there.

Meowbase is signed and notarized by Apple, so it opens without warnings. It needs a Mac with Apple Silicon. It was developed and tested on macOS 27; it is built to run on macOS 11 and later, but older versions have not been tried.

Let an AI agent look, on your terms

Meowbase includes a small server that lets Claude Desktop, Claude Code and other MCP clients read the connections you choose. By default an agent can only read. If you allow it for a connection, an agent can propose a change, and nothing runs until you have read the exact statement in Meowbase and approved it.
