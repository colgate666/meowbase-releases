# Meowbase downloads

This repository holds the downloads and the website of **Meowbase**, a fast, minimal database
viewer for SQLite, PostgreSQL and MySQL on macOS.

**Download:** https://colgate666.github.io/meowbase-releases/ (or the
[latest release](https://github.com/colgate666/meowbase-releases/releases/latest))

Meowbase needs a Mac with Apple Silicon. The disk images are signed and notarized by Apple.
